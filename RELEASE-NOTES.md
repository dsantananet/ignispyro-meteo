# IgnisPyroMeteo 1.2.0-rc.1

Versão experimental para Windows x64. Escolha o instalador `…setup.exe` ou o ZIP `…portable.zip`.
Leia `LEIA-ME.txt`. O ZIP de código-fonte gerado pelo GitHub não é um instalador.

Inclui painel meteorológico independente, logótipo no painel e instalador,
Aldeia do Bispo integrada, estações IPMA, meteogramas ECMWF e observações,
seleção de estações e boletim meteorológico para análise de incêndios.
Mantém o Borda de Água digital para agronomia.
FWI, HDW, humidade dos combustíveis e ocorrências não têm integração nesta versão.
Não é necessária uma chave pessoal para consultar o resumo público da Aldeia.
Os resultados de instalação, execução e desinstalação constam da execução de Actions associada.
Testes automáticos em Windows não equivalem a validação científica dos indicadores.
Linux e macOS não testados. Executáveis sem assinatura digital.
